## 🚀 Live Demo
Visit the live site here: [kunal-lamba.dev](https://kunal-lamba.dev/) *(Note: Replace with actual URL if different)*

## ✨ Key Features
- **Modern UI/UX**: Clean, professional design with a focus on readability and smooth user experience.
- **Dynamic Themes**: Support for both Dark and Light modes with a seamless toggle.
- **Interactive Animations**: 
    - Canvas-based particle background.
    - Interactive Skill Constellation (Galaxy) visualization.
    - Scroll-reveal animations for a premium feel.
- **AI Chatbot Assistant**: A custom-built portfolio assistant to help visitors learn more about my profile.
- **Project Showcase**: Interactive carousel featuring my key projects with links to GitHub.
- **Direct Contact**: Integrated contact form using [EmailJS](https://www.emailjs.com/) for client-side email submission.
- **Fully Responsive**: Optimized for all devices, from mobile phones to high-resolution desktops.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Typography & Icons**: Google Fonts, Skill Icons
- **Integrations**: EmailJS (Form handling), GitHub Readme Stats
- **Development Tools**: Visual Studio Code, Git

## ⚙️ Local Development
To run this project locally, simply clone the repository and open `index.html` in your favorite browser.

1. **Clone the repo:**
   ```bash
   git clone https://github.com/kunal4116452224/latestPortfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd latestPortfolio
   ```
3. **Launch the site:**
   Open `index.html` directly or use a "Live Server" extension in VS Code.
