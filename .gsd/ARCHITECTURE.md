## Overview

A responsive, single-page personal portfolio website built with Vanilla HTML, CSS, and JavaScript. It features dynamic interactive elements like canvas animations, a project carousel, theme toggling, and a contact form integrated with EmailJS. The application is completely structural on the client side without a dedicated backend server.

## Components

### index.html
- **Purpose:** Main structure and content of the portfolio, containing semantic HTML sections (Hero, About, Skills, Projects, Contact). Includes basic SEO tags and links to external fonts/icons.
- **Location:** `./index.html`
- **Dependencies:** Google Fonts, EmailJS script, style.css, script.js

### style.css
- **Purpose:** Styling, responsive layout (CSS Grid/Flexbox), dark/light mode theming using CSS variables, and basic CSS animations/transitions.
- **Location:** `./style.css`

### script.js
- **Purpose:** Handles all client-side interactivity, including:
  - Canvas-based particle animation
  - Theme toggling
  - Smooth scrolling and intersection observers for scroll animations
  - Form submission logic and form validation
  - Interactive skill constellation mapping
- **Location:** `./script.js`
- **Dependencies:** EmailJS API configurations (keys hardcoded)

## Data Flow

1. **User Interaction:** User inputs contact information into the form and clicks submit.
2. **Event Handling:** `script.js` prevents default form submission, validates empty fields.
3. **API Integration:** The contact payload is formatted and passed to `window.emailjs.sendForm()`.
4. **Third-party Transport:** EmailJS routes the email payload to the configured email address using given Service ID and Template ID.
